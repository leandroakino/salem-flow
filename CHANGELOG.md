# Versões do Salém Flow

Cada atualização publicada ganha um número e uma tag no GitHub. A versão aparece na tela de login e no menu do usuário.
Para voltar a uma versão: `git checkout vX.Y` (ou peça ao Claude: "voltar para a v1.2").
